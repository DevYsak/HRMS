## Authorization holes

1. **`app/Livewire/Employees/EmployeeEdit.php:248-250`**: `$scopesApply` covers only `hr_admin` and `manager`. Saving a Director's record nulls `scope_departments` and `scope_shifts`, so every Director stays company-wide (`ApprovalGuard.php:35-57`). Spec §4/§4.1 wants Department Heads (Nikita = UK shift) scoped. **Fix:** add `'director'` to the array. No behaviour change until HR sets a scope.
2. **`app/Policies/EmployeePolicy.php:16-53`**: `view`, `update`, `delete` and `invite` check only `canManageEmployees()` and ignore scope. A department-scoped HR Admin or Director can open, edit, delete or invite any employee by URL (`/employees/{id}/edit|profile|onboarding|offboarding|probation`). **Fix:** append `&& $user->coversEmployee($employee)` to each. Company-wide users are unaffected.
3. **Director write access (`RolesAndPermissionsSeeder.php:152`)**: Spec gives Directors view-dept only. The app lets them edit salary components (`EmployeeEdit.php:531-566`), edit bank/PAN/any HR field (`EmployeeProfile.php:129-151`), soft-delete and **permanently purge** employees with their payslips (`EmployeeIndex.php:131-173`), offboard anyone and set the F&F amount (`OffboardingManager.php:75-120`), and manage assets (`routes/web.php:429`). **Minimal fix:** gate `saveSalary`/`removeSalary` with `canRunPayroll()`, and `forceDelete` to Super Admin. The full fix is a business decision (see Top fixes).
4. **`app/Livewire/Employees/EmployeeDocuments.php:31-85`**: no authorisation in `mount`, `upload` or `delete`. Only the parent route's `role:manage-employees` protects it, so a Director (who lacks `manage_documents`) can list, upload any file type, and hard-delete employee contracts. **Fix:** `abort_unless(auth()->user()->canManageDocuments(), 403)` in all three, plus a `mimes:pdf,png,jpg,jpeg` rule.
5. **`app/Http/Controllers/DocumentController.php:31-59`**: `download`/`view` rely only on the signed URL. Any logged-in user holding a forwarded or leaked link reads any document for 5 minutes. `view` also serves the stored MIME type inline, so an uploaded HTML/SVG file runs as stored XSS on the app origin (upload paths: `EmployeeDocuments.php:50`, `ManagePips.php:153`, `ManagePromotions.php:154`, `WarningLetters.php:133`). **Fix:** add a `DocumentPolicy::view` (reuse `DocumentManager::assertCanAccess` :98-114) with `$this->authorize('view', $document)` in both methods. Serve inline only for pdf/png/jpeg, add `nosniff`, and use `attachment` for everything else.
6. **`app/Livewire/Documents/DocumentManager.php:111,173-175` and `app/Services/EmployeeDashboardService.php:614-616`**: `canApproveFinance()` exposes every payslip-category document to **Directors**, contrary to §4 "Payslips: Director no access". **Fix:** use `canRunPayroll()` instead. Finance, HR and SA keep access.
7. **`app/Livewire/Onboarding/OffboardingManager.php:21,43-47,75-101`**: `$selectedEmployeeId` is unlocked and has no scope or self check. Any `manage_employees` holder (Director included) can write `final_settlement_amount`/`final_settlement_done`, and that amount is paid out via `SalaryCalculationService.php:200-215`. **Fix:** `#[Locked]`. Call `app(ApprovalGuard::class)->assertCanDecide(auth()->user(), $employee)`. Persist `final_settlement_*` only when `auth()->user()->canRunPayroll()`.
8. **`app/Livewire/Onboarding/OnboardingChecklist.php:16,18,44-48`** (and its subclass OffboardingChecklist): `$employeeId` and `$phase` are not `#[Locked]`, mount does not authorise, and none of `toggleComplete`/`updateStatus`/`setBlocked`/`addTask`/`deleteTask` (:50-173) checks anything beyond the route. A scoped HR user can repoint the component to any employee. **Fix:** `#[Locked]` both, and in mount call `$this->authorize('update', Employee::findOrFail($employee))` (scope-aware after hole 2).
9. **`app/Livewire/Profile/EmployeeProfile.php:39,171-203` → `app/Services/Profile/ProfileChangeService.php:115-171`**: `$reviewingId` is unlocked and not tied to `$this->employee`, and there is no self-approval guard. An HR Admin can approve their own bank-account/PAN change request. Likewise `EmployeeEdit::saveSalary` (:531-557) lets HR edit their own salary components. **Fix:** in `approve`/`reject` call `ApprovalGuard::assertCanDecide($reviewer, $request->employee)`. 10. **`app/Http/Middleware/CheckActiveEmployee.php:28`**: only `inactive` is blocked. Resigned, terminated, absconded and archived employees without an exit record can still sign in. **Fix:** `if ($employee->status?->isArchived())`.
11. **`app/Livewire/Documents/DocumentManager.php:116-129`**: `acknowledge($id)` accepts any document id, so an employee can record acknowledgements for documents not addressed to them or not requiring acknowledgement. 12. **`app/Services/ProbationEngine.php:78-100`**: `managerConfirm` has no reporting-line or self check, so a Director can confirm any probation, their own included. **Fix:** `ApprovalGuard::assertCanDecide`.
13. **`OffboardingManager.php:122-131`**: `returnAsset($assetId)` accepts any asset. Low risk (HR-only). **Fix:** constrain to the selected employee's assets.
